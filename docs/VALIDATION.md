# 온담 검증 기록

검증일: 2026-11-15. 모든 계정·이름·주소·일정은 개발용 가상 데이터입니다.

| 구분 | 결과 | 범위 |
|---|---|---|
| 자동 테스트 | 368/368 통과 | 인증·권한·일정 충돌·요청 상태·음성 오류 처리·입력 검증·화면 회귀 |
| 로컬 HTTP 업무 시나리오 | 62/62 통과 | 역할별 로그인·범위 제한·조회·변경안 확인·중복/오류 거절·로그아웃 |
| 브라우저 직접 확인 | 완료 | 가상 사회복지사 로그인, 미처리 요청 조회, 어르신 화면 진입, 방문 약속 전환, 주간 이동 |

초기 자동 검사에서 기존 CLover 로고를 기대하던 2건이 실패했습니다. 새 온담 문자 로고에 맞춰 검사 기대값을 갱신한 후 전체 368건을 다시 실행했습니다. 기능 실패를 숨기기 위해 검사를 제거하지 않았습니다.

## 캡처 해석

- 비서 화면은 **기본 조회 모드**에서 가상 저장 데이터를 조회한 결과입니다. 실제 LLM 추론 성공 화면으로 주장하지 않습니다.
- 화면의 10~11월 일정은 고정된 가상 검증 자료입니다.
- 어르신 화면은 사회복지사 계정에서 여는 미리보기입니다.
- 화면에서 빈 주가 표시되는 경우는 해당 주에 가상 일정이 없기 때문입니다.
- 실제 마이크 녹음, STT 인식률, 실제 LLM 응답 품질, 휴대폰 푸시 수신, 현장 사용자 평가와 운영 부하 검증은 이번 시험에 포함하지 않았습니다.

## 재현

```sh
npm ci
npm test
npm run build:web
```

HTTP 시나리오는 운영 데이터와 분리된 폴더에서 실행합니다.

```sh
node scripts/setup-feature-check.mjs
```

생성된 `tmp/full-feature-data`를 `CLOVER_DATA_DIR`로 지정하고 `PORT=34880`에서 서버를 실행한 뒤 `node scripts/check-features-http.mjs`를 실행합니다. 설정과 시험 계정은 해당 스크립트 안의 가상 fixture 기준입니다. 시험 서버는 외부에 공개하지 않습니다.
